# TMPS labs

This is a repository for labs in the Technical University of Moldova for the
TMPS course. Which are "Tehnici si mechanisme de Proiectare Sofrware", which
is Software Design Techniques And Mechanisms.

Each lab contain the `report.md` file where is written the report for that
lab.

---

## lab 01

First laboratory work is made in C# to demonstrate the 3 out of 5 SOLID
principles.
